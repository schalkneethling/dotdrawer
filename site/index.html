## What goes in the drawer

On first launch, dotdrawer scans your home folder for agent configs, shell startup files and tool configs. You tick the ones you want. Agent configs start ticked.

  • [x] ~/.claude/CLAUDE.md (ticked)
  • [x] ~/.codex/AGENTS.md (ticked)
  • [x] ~/.gemini/GEMINI.md (ticked)
  • [x] ~/.zshrc (ticked)
  • [ ] ~/.gitconfig
  • [ ] ~/.ssh/config
  • [ ] ~/.config/ghostty/config

## How it works

  1. Open the drawer. Click the menu bar icon, or press ⌃⌥⌘D. The shortcut works even when the icon is hidden behind the notch.
  2. Pick a file. Use the mouse, or the arrow keys and Return.
  3. Edit it. The file opens in the editor you chose, or in the app macOS uses for that kind of file.

## Install

Download the latest release, unzip it, and move dotdrawer.app to your Applications folder. It is signed with a Developer ID and notarized by Apple, so macOS opens it without warnings.

Download the latest release

Or, with Homebrew:

brew tap schalkneethling/dotdrawer
brew trust --cask schalkneethling/dotdrawer/dotdrawer
brew install --cask dotdrawer

dotdrawer keeps itself up to date, so a plain brew upgrade skips it.

## Requirements

  • macOS 26 or later
  • An Apple silicon or Intel Mac
  • On macOS 14 or 15, use version 0.2.0
